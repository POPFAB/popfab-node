# Changelog

All notable changes to `popfab` are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project follows Semantic Versioning.

## [Unreleased]

### Added

- Release guardrails: sandbox integration test gate, matching version/tag check, and npm provenance publishing workflow.

## [0.1.0] - 2026-09-24

### Added

- Typed Node.js client with Bearer authentication, timeouts, safe read retries, and typed errors.
- Payments: initiate, get, list, sync, and refund.
- Transfers: banks, account verification, single/bulk initiation, get, and list.
- Virtual accounts and customers resources.
- Timestamp-bound Popfab webhook verification.
- Documentation, examples, sandbox test harness, and GitHub Actions CI.
